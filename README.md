# جمّول | Jamool

منصة تعليمية ترفيهية تفاعلية للأطفال (٣–١٥ سنة) — الجمعية الأهلية الصالحية، عنيزة.

واجهة عربية RTL مبنية بـ **Next.js (App Router) + TypeScript + Tailwind CSS v4**.

## التشغيل

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # بناء الإنتاج
npm run typecheck  # فحص TypeScript
npm run assets     # إعادة توليد الصور من design-source/originals (يتطلب Python + Pillow)
```

## البنية

```text
design-source/originals/   الأصول الأصلية دون تعديل (لا تُنشر)
public/assets/             النسخ المعالجة للويب: brand / characters / icons / illustrations
scripts/                   process-assets.py ، fetch-surahs.mjs
docs/asset-inventory.md    جرد الأصول والملاحظات المفتوحة
src/app/                   الصفحات (الرئيسية + ٨ أقسام + إنجازاتي + استكشف + صفحات المعلومات)
src/components/ui/         أزرار، شرائح، حوار، إشعارات، حالات التحميل/الفراغ/الخطأ
src/components/brand/      الشخصيات، أيقونات الأقسام، الشعار، الزخارف
src/components/layout/     الترويسة، التذييل، رؤوس الصفحات
src/components/home/       مناطق الصفحة الرئيسية
src/components/features/   القارئ، الاختبار، لعبة الذاكرة، مرسم مها، مختبر زيزو، حديقة القيم…
src/data/                  كل المحتوى والبيانات (قصص، حروف، سور، ألعاب، قيم، تحديات)
src/lib/                   brand-assets.ts (خريطة الأصول) ، progress.ts (التقدم المحلي) ، speech.ts
src/app/globals.css        Design Tokens وعوالم ألوان الأقسام
```

مرجع حي لنظام التصميم: `/design-system`.

## ما يعمل فعليًا وما هو تجريبي

| يعمل | تجريبي / غير متاح (ومُعلَّم بذلك داخل الواجهة) |
|---|---|
| قارئ القصص (تكبير الخط، تنقل، قراءة آلية إن توفر صوت عربي بالجهاز) | نصوص القصص نماذج أولية بانتظار المحتوى المعتمد |
| بطاقات الحروف والأرقام + نشاطان بمستويين | لا تسجيلات صوتية |
| قصار السور (١٢ سورة) + وضع الحفظ | التلاوة الصوتية غير متاحة |
| لعبة الذاكرة بثلاثة مستويات | ثلاث ألعاب «قيد الإعداد» |
| المرسم: فرشاة، ممحاة، ألوان، تراجع/إعادة، مسح، حفظ محلي، تنزيل PNG | — |
| مختبر زيزو: مولّد أفكار محلي من قوائم مراجَعة | **لا يوجد ذكاء اصطناعي متصل**؛ المحادثة معطّلة |
| حديقة القيم (٤ أنشطة) والتحديات التدريبية | لا مسابقات رسمية؛ لا حسابات ولا تسجيل دخول |
| النجوم والشارات (localStorage فقط) | صفحات الخصوصية والشروط مسودات |

نص السور مجلوب حرفيًا من نص «تنزيل» العثماني (عبر Al Quran Cloud API) ومخزَّن في `src/data/surahs.json` دون تعديل؛ يلزم اعتماده من جهة شرعية قبل الإطلاق.
